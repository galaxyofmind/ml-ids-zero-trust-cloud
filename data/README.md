# Data Directory

Datasets are **not included** in this repository due to file size. All data is downloaded automatically by `src/preprocess.py`.

---

## Dataset 1: NSL-KDD

| Property | Value |
|----------|-------|
| **Records** | 125,973 (`KDDTrain+.txt`; verify the file before each ingest) |
| **Features** | 41 (post feature selection: **25**) |
| **Attack Categories** | 4 — DoS, Probe, R2L, U2R |
| **Normal:Attack Ratio** | 53.46 : 46.54 |
| **Year** | 1999 (revised 2009) |
| **Source** | University of New Brunswick |

### Download (automatic)

The independent `KDDTest+.txt` split has 22,544 records and is the capstone evaluation set. Fit preprocessing and feature selection on training data only.

```bash
python src/preprocess.py
```

The script downloads from:
```
https://raw.githubusercontent.com/defcom17/NSL_KDD/master/KDDTrain+.txt
```

### Manual Download

- [NSL-KDD at UNB](https://www.unb.ca/cic/datasets/nsl.html)
- [GitHub mirror (defcom17)](https://github.com/defcom17/NSL_KDD)

### Manual Download

CICIDS-2018 requires registration. Download from:
- [CIC CICIDS-2018](https://www.unb.ca/cic/datasets/ids-2018.html)

After downloading, place CSV files in this `data/` directory and update the notebook `02_preprocessing.ipynb` to point to local paths.

## Processed Files (generated by preprocess.py)

After running the pipeline, the following `.npy` files will appear here:

| File | Description |
|------|-------------|
| `X_train.npy` | Training features (shape: ~118,000 × 25) |
| `X_test.npy` | Test features (shape: ~29,600 × 25) |
| `y_train.npy` | Training labels (0=normal, 1=attack) |
| `y_test.npy` | Test labels |

> These files are listed in `.gitignore` and will not be committed to Git.

## Feature Selection

The pipeline applies **Recursive Feature Elimination with Cross-Validation (RFECV)** using `RandomForestClassifier` to reduce the 41 NSL-KDD features to the **top 25 most informative** features.

After running `preprocess.py`, the selected feature names are saved to:
```
results/models/selected_features.csv
```

**Top 15 features by importance** (from paper Appendix B):

| Rank | Feature | Importance |
|------|---------|------------|
| 1 | dst_bytes | 0.1423 |
| 2 | src_bytes | 0.1287 |
| 3 | count | 0.0891 |
| 4 | srv_count | 0.0734 |
| 5–15 | (see Appendix B of research paper) | — |
